# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| 0.1.x   | :x:                |

## Reporting a Vulnerability

If you have a vulnerability to report, please email hablethedev@disr.it **in plain text email** with details on how to reproduce the vulnerability.
Please contain the following in your email:

- What the vulnerability can achieve
- How to reproduce the vulnerability
- Sample code (if applicable)

**English** is the preferred language for reports.

On how to email in plain text: https://useplaintext.email/ or, [search it](https://www.google.com/search?q=how+to+use+plain+text+email+in+%5Bemail+client%5D).
